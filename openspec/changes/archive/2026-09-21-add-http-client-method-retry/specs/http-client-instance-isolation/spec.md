## Purpose

定义声明式 HTTP 客户端对象与其请求执行实例的生命周期关系，减少宿主默认客户端与子包之间的配置和拦截器相互影响，并明确创建时配置继承及共享引用造成的部分隔离边界。

## ADDED Requirements

### Requirement: 客户端对象管理独立请求实例

系统 SHALL 为每个 `@HttpClient` 对象管理一个独立的 Axios 实例，同一对象的所有 HTTP 方法 SHALL 复用该实例，实例级重试拦截器 SHALL 仅注册一次。

#### Scenario: 同一对象的多次方法调用复用实例

- **WHEN** 一个客户端对象先后或并发调用多个装饰的 HTTP 方法
- **THEN** 这些方法使用同一个对象所属的请求实例
- **THEN** 不因属性读取、方法调用或内部重试而重复注册重试拦截器

#### Scenario: 同一客户端类的两个对象相互独立

- **WHEN** 同一个 `@HttpClient` 类被构造两次
- **THEN** 两个对象各自使用独立实例和拦截器集合
- **THEN** 一个对象的方法重试策略和运行状态不影响另一个对象

### Requirement: 宿主与子包的拦截器相互独立

系统 SHALL 不继承宿主默认 Axios 实例已经注册的请求或响应拦截器；双方之后的拦截器注册 SHALL 仅作用于所属实例。子包 SHALL 不修改宿主默认实例的配置或拦截器集合。

#### Scenario: 宿主在对象创建前后注册拦截器

- **WHEN** 宿主分别在客户端对象创建前后向默认 Axios 实例注册请求与响应拦截器
- **THEN** 子包请求均不执行这些宿主拦截器
- **THEN** 宿主自己的请求仍按其原有拦截器集合执行

#### Scenario: 子包启用重试不影响宿主请求

- **WHEN** 子包某方法配置重试并发生符合条件的失败，宿主同时使用默认 Axios 实例发送请求
- **THEN** 子包按方法配置重试
- **THEN** 宿主请求不因子包安装的插件而增加重试或改变配置

### Requirement: 默认配置只提供部分隔离

系统 SHALL 使用创建时的 Axios 默认配置作为实例初始配置来源，并按既有客户端和请求配置覆盖规则发送请求；创建后的普通配置字段修改 SHALL 不在宿主和子包实例之间自动同步。系统 SHALL 明确该边界不包含任意引用的深拷贝或独立运行环境；重试命名空间的配置来源例外遵循 `http-method-retry` 的方法级契约。

#### Scenario: 创建前的普通默认值仍被继承

- **WHEN** 宿主在客户端对象创建前设置默认 `timeout` 和普通请求头，且子包未覆盖它们
- **THEN** 对象的请求继承这些初始值
- **THEN** 不能把该行为描述为恢复 Axios 原始默认值

#### Scenario: 创建后的普通配置修改互不传播

- **WHEN** 对象创建后，宿主改变默认 `timeout` 或普通请求头字段
- **THEN** 已存在对象的请求继续使用创建时取得的值，除非本次客户端或请求配置显式覆盖
- **THEN** 对子包实例普通配置的修改不会反向改变宿主默认配置

#### Scenario: 可变引用仍可能共享

- **WHEN** 创建时的默认配置包含 Agent、类实例、函数闭包或数组中的对象引用
- **THEN** 系统不承诺复制这些引用指向的内部状态
- **THEN** 文档说明修改共享对象内部状态仍可能影响双方，空 `headers` 对象也不代表清空继承请求头
